# Passerelle Trotteurs Intranet

Private repository for the Passerelle Trotteurs intranet project.

## Current status

The live platform has been audited without changing production data or
configuration. We have effective control of the Drupal application and
authenticated access to its o2switch technical hosting account, but several
contractual and recovery accounts still need to be transferred before the
platform can be considered fully owned.

Start here:

- [Ownership and access audit](docs/OWNERSHIP-AUDIT-2026-07-23.md)

## Scope

This repository is intended to centralize:

- application source code and deployment documentation;
- infrastructure and service inventories;
- operating procedures and handover notes;
- issue tracking and future development work.

Production passwords, API keys, recovery codes, database dumps, and other
secrets must not be committed to this repository.

Credentials must be shared through an approved password manager, never through
GitHub issues, pull requests, documentation, or source files.
